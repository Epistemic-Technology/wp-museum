# Museum for WordPress

A museum-management application built for modern WordPress.

## Features

- Define custom **object kinds** (e.g. artifacts, specimens, instruments) with custom fields.
- Object **image galleries**.
- **Collections** with hierarchical parent/child relationships.
- A rich set of **blocks** for search, display, and navigation.
- **REST API** (`wp-museum/v1`) for objects, collections, kinds, fields, and image attachments.
- **Museum Remote** companion plugin for embedding collections from a central museum site on other WordPress sites.
- **Capability-based security** — custom roles and capabilities control access independently of standard post permissions.
- Fully internationalizable (`wp-museum` text domain).

## Requirements

- WordPress 6.9 or later
- PHP 8.2 or later

Head to [Installation](installation.md) to set the plugin up, then [Object Kinds & Fields](object-kinds.md) to define your first object type.
